# YourPlant - Smart Farming Platform

## Overview
This project was developed as part of the PIDEV - 2nd Year Engineering Program at **Esprit School of Engineering** (Academic Year 2026-2027).
It is an application designed to help farmers progress faster and safer in their agricultural activities.

## Features
- Farm management and monitoring
- Safety tracking and alerts for agricultural processes
- Data analytics to help farmers progress faster
